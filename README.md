# BookNook

Live Site: https://booknook-frontend-ydya.vercel.app/

BookNook is a small online library where you can add a book, borrow a book and return it.

## Features
- Email/password and Google login with BetterAuth
- Private routes protected with login and JWT
- Add, update and delete your own books
- Borrow and return books with available copy tracking
- Responsive design with a Swiper banner slider
